# Обновление Оборудыша — 06.07.2026

## Добавлено
- **Админ дня в ежедневной сводке (22:00)** — в конце сообщения выводится «Админ дня: @ник (N действий)». Считается по новой таблице `actions`, где фиксируются все действия кураторов
- **Заявки на завтра с кураторами вместо цифр** — вместо «Завтра выдач: 7 · возвратов: 4» теперь перечисляются конкретные заявки: «ID {id} — {куратор}», удобно видеть кто что выдаст и кто примет возврат
- **Кнопка «Обновить БД» в панели старшего** — пересверивает всех верифицированных по справочникам MB/org. Пропавшие из списка автоматически получают статус pending. Готово к работе со справочником ролей
- **Автозаполнение отделов и роли по username Telegram** — если настроен справочник (DIRECTORY_FILE), при регистрации отделы и роль подставляются автоматически. Доработан `make_members.py`: новый режим `--directory` для генерации `directory.csv` (формат: username;ФИО;отдел1,отдел2;роль). Без справочника работает по старому шаблону (ручной ввод)
- **Markdown-формат статистики** — кнопка «Статистика (MD)» в панели старшего теперь отправляет .md файл вместо CSV. Бот присылает готовый markdown с таблицами — удобно копировать в Telegram

## Изменено
- **Ежедневная сводка** — полностью переписана: теперь показывает заявки на завтра с кураторами (по строке для каждой), а не просто счётчики
- **Таблица `actions`** — новая, хранит `admin_id`, `kind` (requests/b626), `ref` (id заявки), `action` (тип действия) и `ts` (время). Понадобится для статистики действий админов
- **Функция `directory()`** — новая функция чтения справочника username → {name, deps, role}. Возвращает пустой словарь если файла нет (без ошибки)
- **`make_members.py`** — полностью переписан: поддерживает два режима: обычный (org_members.csv) и `--directory` (directory.csv для автозаполнения)

## GoPro и warnings
- **GoPro HERO 12** больше не вызывает предупреждение про объектив (экшн-камера)
- **Камеры (не GoPro)**: мягкое предупреждение — «К камере рекомендуем добавить объектив»
- **Свет без аккумов**: предупреждение убрано

## MD выгрузка вместо CSV
- Кнопка «Статистика (MD)» в панели старшего теперь:
  - Показывает статистику в MD формате прямо в приложении
  - Имеет 3 кнопки для выгрузки в личку: заявки, 626, админы (файлы .md вместо .csv)
